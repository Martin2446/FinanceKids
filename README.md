ПРЕГЛЕД НА ПРОГРАМАТА:
────────────────────────────────────────────────────────────────────────────────

Finance Kids е интерактивна образователна платформа, предназначена за деца и
младежи, която ги учи на основите на финансовата грамотност чрез игра, 
лекции и тестване.

ТЕХНОЛОГИЯ:
────────────────────────────────────────────────────────────────────────────────
Backend:  FastAPI (Python)
Frontend: HTML, CSS, JavaScript
Database: SQLite3
Server:   Localhost (http://127.0.0.1:8000)

ОСНОВНИ ФУНКЦИИ:
────────────────────────────────────────────────────────────────────────────────

1. АВТЕНТИФИКАЦИЯ
   • Регистрация на нов профил
   • Вход с потребителско име и парола
   • Гост режим без регистрация
   • Съхранение на профилни данни в база данни

2. ИГРА
   • 3 нива на трудност: Лесно, Средно, Трудно
   • Въпроси с 4 възможни отговора
   • Различно време за всяко ниво
   • Система за точки
   • Резюме на резултатите след завършване
   • Таймер за играта

3. СИСТЕМА ЗА ЗНАЧКИ
   • Първа касичка (10 точки)
   • Пестеливец (50 точки)
   • Ловец на спестявания (100 точки)
   • Майстор на бюджета (200 точки)
   • Милионер (500 точки)
   • Перфектна игра (всички въпроси верни)

4. АКАДЕМИЯ - ЛЕКЦИИ
   • Образователни лекции по финансови теми
   • Тестове към всяка лекция
   • Проследяване на завършени лекции
   • Система за оценяване (100% = завършена)

5. КЛАСАЦИЯ НА ТОП 10 ПРОФИЛА
   • Реално време ранкиране на най-добрите играчи
   • Показване на точки на всеки играч
   • Текущ потребител отличен на класацията

6. АДМИН ПАНЕЛ
   • Управление на въпроси
   • Управление на лекции и тестове
   • Управление на потребители
   • Трудност: Лесно, Средно, Трудно

API МАРШРУТИ:
────────────────────────────────────────────────────────────────────────────────

ВЪПРОСИ:
  GET  /api/questions?difficulty={easy|medium|hard}
       - Получава въпроси по трудност

РЕГИСТРАЦИЯ И ВХОД:
  POST /api/register
       - Регистрира нов потребител
  POST /api/login
       - Вход на съществуващ потребител

ПОТРЕБИТЕЛИ:
  POST /api/users/update_points
       - Обновява точките на потребител
  GET  /api/leaderboard
       - Получава топ 10 класация

ЛЕКЦИИ:
  GET  /api/lectures
       - Получава всички лекции
  POST /api/admin/lectures
       - Создава нова лекция (админ)
  DELETE /api/admin/lectures/{lecture_id}
       - Изтрива лекция (админ)

АДМИН ФУНКЦИИ:
  POST /api/admin/questions
       - Добавя нов въпрос
  DELETE /api/admin/questions/{difficulty}/{question_id}
       - Изтрива въпрос
  GET  /api/admin/users
       - Получава всички потребители (админ)
  POST /api/admin/users
       - Създава потребител (админ)
  DELETE /api/admin/users/{user_id}
       - Изтрива потребител (админ)

ДАННИ, СЪХРАНЯВАНИ В ПРОФИЛА:
